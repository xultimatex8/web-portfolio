Zeolite es una aplicación web para organizar, diseñar y analizar historias y universos ficticios. Combina un backend en Python con una base de datos de grafos Neo4j que almacena y conecta toda la información narrativa como un grafo, junto con un frontend interactivo en React.

Un espacio de trabajo visual reúne las notas dispersas en un único lugar, diferenciando claramente personajes, eventos y localizaciones, y permite definir atributos personalizados para adaptarlo al universo de cada historia. Un sistema de análisis examina continuamente el grafo y alerta, mediante un panel interactivo, de problemas como personajes sin interacciones, eventos sin impacto en la trama o localizaciones aisladas.

## Funcionalidades

- **Organización de historias**: editor visual de grafos para estructurar los elementos narrativos.
- **Creación de entidades y relaciones**: define personajes, eventos y localizaciones con atributos personalizados.
- **Análisis de consistencia**: detección automática de inconsistencias narrativas mediante un panel de análisis.
- **Base de datos de grafos**: Neo4j (NoSQL) para almacenar información altamente conectada.
- **Desarrollo rápido**: creación ágil de la aplicación con FastAPI y React.

## Retos técnicos

- Diseñar un modelo de datos estructurado que equilibrara tipos de entidades predefinidos con la posibilidad de extenderlos mediante atributos personalizados.
- Traducir los conceptos propios de una base de datos de grafos a una interfaz intuitiva.
- Mantener la visualización del grafo fluida y legible a medida que aumentaba el número de entidades y relaciones.
- Diseñar e implementar consultas de análisis en Neo4j capaces de detectar automáticamente inconsistencias narrativas.

## Aprendizajes

- Neo4j me dio experiencia práctica en modelado de grafos y estructuras NoSQL, y me mostró cómo la base de datos adecuada simplifica mucho la representación de información altamente conectada.
- Convertir rápidamente una idea en una aplicación funcional, iterando sobre el modelo de datos y las funcionalidades.
- Desarrollar el editor interactivo de grafos me dio experiencia práctica en interfaces basadas en grafos con React, incluyendo la visualización de datos conectados y el diseño de interacciones intuitivas.
