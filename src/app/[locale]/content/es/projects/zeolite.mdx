# Zeolite

Zeolite es una aplicación web para organizar, diseñar y analizar historias y universos ficticios. Combina un backend desarrollado en Python con una base de datos de grafos Neo4j para almacenar y conectar toda la información narrativa como un grafo, junto con un frontend interactivo desarrollado en React.

Una de sus principales funcionalidades es un espacio de trabajo visual que reúne en un único lugar todas las notas relacionadas con una historia, diferenciando claramente personajes, eventos y localizaciones. Gracias a la flexibilidad de la base de datos de grafos, los usuarios pueden describir cada elemento de forma estructurada y definir atributos personalizados para adaptar la aplicación a las necesidades de su universo ficticio.

La plataforma también incorpora un sistema de análisis que examina continuamente el grafo de la historia para detectar errores e inconsistencias narrativas. A través de un panel interactivo, alerta de problemas como personajes sin interacciones, eventos que no afectan a la trama o localizaciones aisladas, ayudando a mantener una historia coherente y bien conectada.

## Características principales

- **Organización de historias**: editor visual de grafos para estructurar los elementos narrativos.
- **Creación de entidades y relaciones**: define personajes, eventos y localizaciones con atributos personalizados.
- **Análisis de consistencia**: detección automática de inconsistencias narrativas mediante un panel de análisis.
- **Desarrollo rápido**: creación ágil de la aplicación utilizando FastAPI y React.
- **Base de datos de grafos**: Neo4j como base de datos NoSQL para almacenar información altamente conectada.

## Retos

Desarrollar Zeolite supuso afrontar diversos retos técnicos:

- Diseñar un modelo de datos estructurado que equilibrara tipos de entidades predefinidos con la posibilidad de extenderlos mediante atributos personalizados.
- Traducir los conceptos propios de una base de datos de grafos a una interfaz intuitiva para el usuario.
- Mantener la visualización del grafo fluida y legible a medida que aumentaba el número de entidades y relaciones.
- Diseñar e implementar consultas en Neo4j capaces de detectar automáticamente inconsistencias narrativas.

## Lecciones aprendidas

Zeolite me permitió introducirme en las bases de datos de grafos mediante Neo4j, adquiriendo experiencia práctica en modelado de grafos y estructuras de datos NoSQL. También me mostró cómo elegir la base de datos adecuada puede simplificar enormemente la representación de información altamente conectada.

Trabajar en este proyecto también me enseñó a convertir rápidamente una idea en una aplicación funcional, iterando continuamente sobre el modelo de datos y las funcionalidades.

Por último, desarrollar el editor interactivo de grafos me proporcionó experiencia práctica en la creación de interfaces basadas en grafos con React, incluyendo la visualización de datos conectados y el diseño de interacciones intuitivas.
