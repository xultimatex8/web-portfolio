UltimateWatch es una aplicación web que unifica catálogos multimedia y facilita coordinar sesiones de visualización remotas con amigos. Se conecta a las APIs públicas de TMDb y Watchmode para ofrecer un buscador unificado donde consultar información de películas y series y ver en qué plataformas de streaming están disponibles.

Su característica principal es un módulo social para crear salas virtuales en las que los participantes coordinan la sesión mediante un temporizador sincronizado controlado por el anfitrión, una lista de reproducción interactiva y un chat integrado en tiempo real.

## Funcionalidades

- **Búsqueda unificada**: consulta películas y series con TMDb y Watchmode, mostrando su disponibilidad en plataformas de streaming en tiempo real.
- **Amigos**: añade amigos mediante el envío y aceptación de solicitudes.
- **Eventos**: crea espacios sociales para coordinar sesiones de visualización remotas con amigos.
- **Calendario de eventos**: consulta los eventos a los que te has unido.
- **Votaciones**: organiza votaciones para decidir qué contenido ver durante un evento.
- **Reproducción sincronizada**: un temporizador controlado por el anfitrión mantiene a todos los participantes sincronizados.
- **Lista de reproducción interactiva**: añade y organiza el contenido que se verá durante la sesión.
- **Chat en tiempo real**: mensajería integrada para comentar la sesión mientras se desarrolla.
- **Administración basada en roles**: gestiona permisos y accesos dentro de cada sala.

## Retos técnicos

- Gestionar el proyecto de forma individual, desde la planificación y estimación hasta el desarrollo y las pruebas, siguiendo Scrum.
- Diseñar una estrategia de herencia en la base de datos que pudiera escalar de forma eficiente.
- Implementar comunicación en tiempo real de baja latencia con WebSockets para temporizadores sincronizados, chat y eventos de las salas.
- Combinar los datos de TMDb y Watchmode en un catálogo único y consistente, respetando las políticas de uso de cada API.
- Estimar y descomponer correctamente las tareas del proyecto.

## Aprendizajes

- Gestionar un proyecto de esta envergadura de forma individual, aplicando metodologías ágiles y priorizando un MVP para cumplir los objetivos de cada sprint.
- Investigar las tecnologías antes de empezar (por ejemplo, evaluar NestJS por su arquitectura modular) y validar previamente las APIs externas evitó problemas inesperados más adelante.
- Los WebSockets me dieron experiencia práctica en comunicación orientada a eventos, gestión de clientes conectados y sincronización de varios usuarios en sesiones colaborativas.
- El diseño de la base de datos importa para la mantenibilidad: cambiar la estrategia de herencia con el proyecto avanzado solo fue posible porque el código estaba cohesionado y desacoplado.
- Hay que descomponer bien las tareas y no subestimar las que parecen sencillas.
