Zeolite is a web app for organizing, designing and analyzing stories and fictional universes. It combines a Python backend with a Neo4j graph database that stores and connects all narrative information as a graph, alongside an interactive React frontend.

A visual workspace brings scattered notes together in one place, clearly distinguishing characters, events and locations, and lets users define their own custom attributes to fit their fictional world. An analysis system continuously examines the story graph and alerts users, through an interactive dashboard, to issues such as characters with no interactions, events with no impact on the plot or isolated locations.

## Features

- **Story organization**: visual graph editor for structuring narrative elements.
- **Entity & relationship creation**: define characters, events and locations with custom attributes.
- **Consistency analysis**: automatic detection of narrative inconsistencies through a dashboard.
- **Graph database**: Neo4j (NoSQL) to store highly connected story data.
- **Quick prototyping**: fast application development with FastAPI and React.

## Technical challenges

- Designing a structured data model that balances predefined entity types with extensibility through custom attributes.
- Translating graph database concepts into an intuitive user interface.
- Keeping the graph visualization responsive and readable as the number of entities and relationships grows.
- Designing and implementing graph analysis queries in Neo4j to automatically detect narrative inconsistencies.

## Takeaways

- Neo4j gave me hands-on experience with graph modeling and NoSQL data structures, and showed how the right database can greatly simplify representing highly connected data.
- Quickly turning an idea into a functional application, iterating on the data model and features.
- Building the interactive graph editor gave me practical experience with graph-based interfaces in React, including visualizing connected data and designing intuitive interactions.
