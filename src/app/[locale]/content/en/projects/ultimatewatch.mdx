UltimateWatch is a web app that unifies multimedia catalogs and makes it easier to coordinate remote viewing sessions with friends. It connects to the public APIs of TMDb and Watchmode to provide a single search where you can check movie and TV show details and see which streaming platforms they are available on.

Its core feature is a social module for creating virtual rooms where participants coordinate the session through a synchronized timer controlled by the room host, an interactive playlist and an integrated real-time chat.

## Features

- **Unified search**: consult movies and TV shows across TMDb and Watchmode, with real-time availability by platform.
- **Friends**: make friends by sending and resolving friend requests.
- **Events**: create social spaces to coordinate viewing sessions with friends remotely.
- **Event calendar**: keep track of the events you have joined.
- **Voting**: run a vote to decide which content to watch during an event.
- **Synchronized playback**: a host-controlled timer keeps every participant watching in sync.
- **Interactive playlist**: queue and manage the content to watch during a session.
- **Real-time chat**: integrated messaging to discuss the session as it happens.
- **Role-based administration**: manage permissions and access within each room.

## Technical challenges

- Managing the entire project individually, from planning and estimation through development and testing, under Scrum.
- Designing a database inheritance strategy that could scale efficiently.
- Implementing low-latency real-time communication with WebSockets for synchronized timers, live chat and room events.
- Combining data from TMDb and Watchmode into a single, consistent catalog while respecting each API's usage policies.
- Estimating and breaking down tasks accurately.

## Takeaways

- Managing a project of this scale on my own, applying agile practices and MVP prioritization to hit sprint deadlines.
- Researching technologies before development (for example, evaluating NestJS for its modular structure) and validating both external APIs in advance avoided unexpected issues later.
- WebSockets gave me practical experience in event-driven communication, handling connected clients and keeping multiple users synchronized in collaborative sessions.
- Database design choices matter for maintainability: switching inheritance strategies mid-project was only manageable because the codebase was cohesive and decoupled.
- Break tasks down thoroughly, and never underestimate seemingly simple ones.
