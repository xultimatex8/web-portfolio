UltimateGGx is a web app for advanced League of Legends match analysis, built on the Riot Games API and a full reconstruction of each match's state from timeline data. Beyond flat statistics, it offers a visual panel to explore how a match unfolds: gold, level and inventory for each player at any moment, with the most relevant events placed at their exact point on the timeline.

The longer-term goal is to simulate counterfactual scenarios (altering a kill, an objective or a positioning change in a fight) to estimate how the game would have evolved and pinpoint the most relevant moments.

## Features

- **Summoner lookup**: search for a summoner and check their profile, rank and recent match history across draft and ranked queues.
- **Match details**: review each match with player KDA, items, duration, damage and other key stats.
- **Match timeline**: see every relevant event (kills, objectives, etc.) in chronological order, with a detail view on click.
- **Approximate minimap**: browse a minimap with approximate player positions (up to a 1-minute margin of error) synced to the selected event.
- **Scoreboard replay**: scrub through the match to see gold, level and items for each player at different moments, tied to the selected event.
- **Error handling & responsiveness**: 404 and 500 error pages, error handling throughout the application and a responsive design.

## Technical challenges

- Learning C#, .NET and Angular from scratch, with no prior experience, and applying them in a real end-to-end project.
- Processing Riot Games API data, which nests objects within objects, to extract only the relevant information.
- Deriving metrics the API doesn't expose directly. A player's KDA requires walking through every kill event they were involved in and determining whether they acted as killer, victim or assistant; reconstructing a build at a given moment requires analyzing the full purchase history while accounting for sales, undos and destroyed items.
- Reconstructing the match's temporal state (gold, level, position and inventory) from discrete timeline events, staying consistent across every selectable point in time.
- Keeping the minimap, the scoreboard and the event timeline in sync, so that selecting an event or dragging the scrubber updates the whole interface to the same moment of the match.
- Keeping an information-dense interface (minimap, timeline and scoreboard together) responsive.
- Designing robust error handling, with 404/500 pages and error control throughout.

## Takeaways

- With a solid grasp of the fundamentals, you become productive in a new stack (C#, .NET, Angular) quickly.
- Building my own intermediate models to summarize and clean the Riot API's data before it reaches the UI makes the presentation layer much simpler than consuming the raw objects directly.
- Reconstructing KDA or a player build from raw events gave me real practice in data processing and in algorithms that accumulate state from a list of time-ordered events.
