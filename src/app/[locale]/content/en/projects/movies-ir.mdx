Movies Information Retrieval is a collaborative project to build and compare information retrieval models on a corpus of movie reviews. It provides a Jupyter-based application for searching and analyzing reviews, exploring how different retrieval strategies affect the results.

It implements two complementary models: a Boolean model, based on exact term matching and logical operators, and a TF-IDF free-text model, which ranks documents by relevance using term frequency and inverse document frequency weighting.

## Features

- **Boolean retrieval**: exact-match search using logical operators over an inverted index.
- **TF-IDF retrieval**: free-text search ranked by term frequency-inverse document frequency weighting.
- **Text preprocessing**: tokenization, normalization and cleaning of movie reviews with NLTK.

## How to use it

If the notebook hasn't been executed yet, click **Run** in the top toolbar and select **Run All Cells**. Once finished, the interactive interface of each retrieval system opens in sequence. To use one specific interface afterwards, press **Ctrl + Enter** on its cell.

To exit any interface, type:

```text
salir
```

and press **Enter**.

> **Note**: the first run may take a few moments while the indexes are created and the necessary resources are loaded.

## Technical challenges

- Designing an inverted index structure that supports both Boolean and TF-IDF retrieval efficiently.
- Preprocessing a large collection of movie reviews consistently, handling tokenization, stopwords and normalization without losing relevant information.
- Implementing TF-IDF weighting and similarity scoring correctly, and validating that the ranking matched the expected relevance.

## Takeaways

- Moving from information retrieval theory to a working system that indexes and queries real text data.
- Comparing Boolean and TF-IDF retrieval side by side clarified the trade-offs between exact-match search and ranked relevance.
- Using NLTK for text preprocessing and Scikit-learn for vectorization strengthened my Python data skills, and showed how much preprocessing quality affects retrieval results.
